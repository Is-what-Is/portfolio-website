### Credit Rating Predictor App

### What the app does

The Credit Rating Predictor is a web app that I made with Streamlit. A user enters ten financial details, and the app predicts if the user's credit rating is Good or Poor. The app also shows a confidence value for the prediction.

### Model selection

Logistic regression gave the best results of all the classifiers that I tested, so the app uses it. I trained a new logistic regression model for the app.

The original dataset uses many features that a typical person does not know, for example the credit mix or the number of credit inquiries. For the app, I kept only ten features that a user can easily find:

- Age
- Monthly in-hand salary
- Number of bank accounts
- Number of credit cards
- Interest rate
- Number of loans
- Outstanding debt
- Credit history age
- Amount invested monthly
- Monthly balance

These ten features are the input fields in the app. I removed the Standard class, so the model has only two classes: Good and Poor.

### Training

I used the same data processing as in the random forest work. The split uses `Customer_ID`, so all records for one customer are in the train set or the test set, never both. This prevents data leakage.

The model is a pipeline with a `StandardScaler` and a `LogisticRegression`. A grid search with grouped cross-validation found the best settings: L2 penalty, $C = 0.001$, and balanced class weights. I saved the pipeline as `model.pkl`, and the app loads this file.

### Decision threshold

The model gives the probability that the credit rating is Good. If this probability is 50% or more, the app shows Good. If it is less than 50%, the app shows Poor.

You can move this threshold. A higher threshold makes the model more careful before it predicts Good. I kept the threshold at 50% because it gives a high recall for the Good class (0.93). The model finds almost all users who have a good credit rating.

### Confidence

The confidence value is the probability that the model gives for the predicted class:

- If the prediction is Good, the confidence is the predicted probability.
- If the prediction is Poor, the confidence is 1 minus the predicted probability.

The confidence is an estimate, not a guarantee. If the input values are far outside the values in the training data, the estimate is less reliable.
